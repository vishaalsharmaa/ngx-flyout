Examples

Every feature of ngx-flyout, one example each. Open them, try Escape, × and the buttons, and switch to Code to copy the source.

Give the flyout a #ref and call open(). Includes a sub-heading.

The parent owns the state with [(opened)]. Escape, × and, with hideOnBackdropClick, a click outside update it too.

opened: {{ settingsOpen() }}

A form with Save / Cancel outputs. showFooter="false" hides the built-in buttons and the parent closes the flyout.

closeOnConfirm="false" keeps it open while saving; the parent calls close(). showCloseButton="false" hides the ×.

Put any icon inside the flyout with ngxFlyoutIcon. It shows in a tile next to the heading.

Replace the Cancel / OK buttons with anything using ngxFlyoutFooter.

Rename the buttons with confirmLabel / cancelLabel and change the colour with the --ngx-flyout-accent CSS variable.

Add animation="slide" and the flyout slides in from the right and back out on close. Animation is off by default.
